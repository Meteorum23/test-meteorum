# test.meteorum.fr

Site statique minimal destiné à vérifier la chaîne de publication Mac → GitHub → OVH.

## Contenu

- `index.html` : toute la page, y compris ses styles.
- Aucun JavaScript.
- Aucune dépendance externe.
- Aucun cookie ni mécanisme de suivi.
- Page marquée `noindex` pendant la phase de test.

## Prévisualisation

Ouvrir directement `index.html` dans un navigateur suffit pour consulter la page.

## Publication

Le fichier `index.html` devra être placé à la racine du dossier associé au sous-domaine `test.meteorum.fr` sur l’hébergement OVH.
